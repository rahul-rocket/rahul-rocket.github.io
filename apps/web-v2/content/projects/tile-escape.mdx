## Overview

An 8×8 puzzle: reach the gold tile before the falling blocks crush you. Every
move the red blocks fall one row and a new row drops in — waiting is a move
too. It started as a single `index.html`, which is preserved as the
behavioural spec.

## The Decision

Write the ~180-line rules core twice on purpose — once in TypeScript with no
DOM or React, once in Dart — rather than add a code-generation step for so
little code. Rendering, input and persistence stay per-platform.

## Challenges & Solutions

Two cores can diverge silently. The guard is the test suites: they mirror each
other case for case, so a rule change that lands in only one language shows up
as suites that stop lining up.

## Outcome

An installable, offline-capable Next.js 15 PWA and a Flutter app with the same
rules, and a contributor guide that states the one thing to know.
