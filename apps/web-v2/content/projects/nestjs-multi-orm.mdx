## Overview

A NestJS module that integrates TypeORM and MikroORM so a project can use
either — or both in the same codebase.

## Architecture

A repository pattern abstracts database operations away from the ORM; custom
decorators inject the right repository for the configured ORM; each ORM keeps
its own configuration, including MikroORM migrations and soft delete.

## Outcome

Services depend on a repository, not on an ORM, so moving between the two is a
configuration decision rather than a rewrite.
