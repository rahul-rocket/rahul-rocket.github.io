## Overview

A multi-factor decision-support indicator for NIFTY 50 and BANKNIFTY, plus a
backtest strategy built from the same engine. It is explicit that a signal is
not a trade recommendation: it means a set of technical conditions lined up on
a closed candle.

## The Problem

TradingView's Pine Script cannot share code between an indicator and a
strategy unless you publish a library. Copy the logic and the two drift apart,
and a backtest that no longer matches the live signals is worse than none.

## Architecture

All logic lives in `src/core.pine`. The pipeline runs market-regime no-trade
filters, higher-timeframe trend, VWAP/EMA, momentum, volume, support and
resistance, breakouts and risk/reward into a 0–100 score. A CALL or PUT needs
the score threshold, every hard gate, no directional veto and no no-trade
condition — no single indicator can trigger one. Signals evaluate on closed
candles only, so they do not repaint.

## Outcome

Both scripts are generated artifacts, and CI makes editing one by hand a
failing build rather than a silent divergence.
